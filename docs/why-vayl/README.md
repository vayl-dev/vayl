# Why Vayl

**Vayl is the reconciling memory layer for AI agents.** Most agent memory _accumulates_ — it saves every fact and later hands your agent a value that used to be true. Vayl **reconciles** instead: a new value supersedes the old, a removal actually retracts, and history stays queryable and auditable.

These pages make the case — the guarantee, why the common approach fails, and who needs it most.
