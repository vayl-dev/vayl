# Getting started checklist

* [ ] **Install** — `pip install vayl-mcp`.
* [ ] **Choose an LLM** — set `OPENAI_API_KEY`, or point `OPENAI_BASE_URL` at a local model. With nothing set, Vayl uses a local Ollama endpoint.
* [ ] **Add Vayl to your MCP client** — see the Quickstart.
* [ ] **Store a fact** — tell your agent something, then ask it back.
* [ ] **(Team) Deploy vayl-server** — run the authenticated HTTP server and create your first admin.
