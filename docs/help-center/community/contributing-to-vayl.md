# Contributing to Vayl

Vayl is open source under Apache-2.0, and contributions are welcome.

* **Report a bug or request a feature** — open a [GitHub issue](https://github.com/vayl-dev/vayl/issues).
* **Contribute code** — the repository has a `CONTRIBUTING` guide with setup, tests, and project layout. New behaviour needs a test, and the offline test suite must stay green.
* **Security** — please report vulnerabilities privately rather than in a public issue; see the repository's `SECURITY.md`.

Start at [github.com/vayl-dev/vayl](https://github.com/vayl-dev/vayl).
