# v0.5.1 — Hardening patch

_26 September 2026_

## Added

* `VAYL_DECRYPT_CACHE=off` keeps plaintext in process memory only while a call runs, at a speed cost (at 1,000 facts, `recall` 59 → 273 ms).

## Fixed

* **Schema migrations are atomic on SQLite.** Pending migrations and their ledger rows commit as one `BEGIN IMMEDIATE` transaction, which also locks out other processes sharing the file.
* `VAYL_VECTOR_CACHE=0` disables the vector cache instead of failing on the first recall.

No action needed to upgrade.
