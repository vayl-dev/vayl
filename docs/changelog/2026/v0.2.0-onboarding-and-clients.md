# v0.2.0 — Onboarding and clients

_28 July 2026_

## Added

* **`vayl-demo`.** Runs the real engine on a scripted conversation with no keys or network. `--live` uses a reachable LLM.
* **Python client `vayl.Vayl`.** Call `remember`, `recall` and any tool as methods instead of MCP JSON, over stdio (spawns `vayl-mcp`) or authenticated HTTP.
* **TypeScript client** (`clients/typescript`). The same surface for TS/JS agents.
* **Slot-schema presets.** `VAYL_SLOT_SCHEMA=preset:clinical` (also `finance`, `support`) loads a bundled declared-slot schema.

## Changed

* **Pre-LLM dedup.** A verbatim restatement of facts that are all still active skips the extractor entirely. Disable with `VAYL_DEDUP_PREFILTER=off`.

## Infrastructure

* OpenSSF Scorecard, CodeQL and Dependabot; least-privilege, SHA-pinned CI; private vulnerability reporting.
