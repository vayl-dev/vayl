# v0.3.0 — FastMCP migration

_29 July 2026_

## Changed

* **Standalone FastMCP** (`fastmcp>=3,<4`) replaces the bundled `mcp.server.fastmcp`, which MCP SDK 2.0 removed.
* **Scope-aware clients.** FastMCP rejects unknown tool arguments, so the Python and TypeScript clients now learn each tool's parameters on connect and send `user_id` / `agent_id` / `run_id` only to tools that accept them.
